### 站点的由来

>雪沫乳花浮午盏，蓼茸蒿笋试春盘。人间有味是清欢。
——苏轼《浣溪沙·细雨斜风作晓寒》

原因很简单：想找个受限较少的地方记录经验、见解、感受等。

域名方面，首先想到的是动漫元素，但我又不想放弃“古风”，同时希望名称比较个性化（尽量不要重名）。拟定了几个名称，结果在网上都有相似或一样的名称被人抢先了，于是继续改。 ~~最终摆烂，随便找了俩词拼凑了下，就成了现在这样（虽然还是难以避免“重名”）。~~ 站点名称后来略作改动，但域名是动不了了。（说回来，现在这个域名有“烂大街”的嫌疑，将来或许会换一个。你问我为什么不用拼音及缩写？因为长度和重名率……）

（虽说起源于喜马拉雅山脉的樱花也能和“古风”搭点边，亦有诗句，如“小园新种红樱树，闲绕花枝便当游”；但相比于梅兰竹菊等植物，其地位、意蕴、受欢迎度都不高（注：古人“樱花”和“樱桃花”是不分的））

我没有弄什么“全网统一名称头像”之类，而且我浏览的东西比较杂（甚至我自己都不知道浏览过哪些地方），再加上各种“巧合”，如有撞名，纯属意外。“原创角色”没有，有也是等我学会绘画才可能。

说回内容，涉及技术类的可能较多，间或练练写作，也有搬运转载记录。随手写些文字，若语言拙劣则进行修改。经验记录类的内容，若无说明，则表明该文内容我事先尝试过，在我的设备上能够运行起来并获得相应的结果，真实性肯定是有的（不过不敢保证其他人按照那些方法一定能成功）；未尝试或失败的则会注明。（本站技术类的文章几乎无“完稿”一说，发布时有一定的完成度，但将来可能会继续更新）

所有转载、参考的内容，除非原文难以寻找，均会在文中注明出处；若在文章中转载或非人工编写的内容占比过多，则该文章会在标注内容出处的基础上，将`copyright`会被设置为`false`，即结尾不显示本站版权信息。

某些文章会因其内容（如文采、隐私、范围等）原因被我进行特殊设置，包括但不限于在文中使用明显提示、文章设置密码、关闭评论框等，请知晓。 ~~如继续浏览本站，需做好可能会阅读到板式混乱、画面奇特、语言暴走、阴阳怪气、文笔拙劣、时间不对、内容跳跃、多而不精、拖更很久等的内容，请悉知~~ 。

更新时间不固定，一般想到哪写到哪，最终汇集整理，若能够凑成文章则发布。至于旧文，则会加以修改后酌情考虑当时完稿时间进行修改。你所看到页脚那个计时器是此站点建立时间，你看到文章完成时间在此之前是正常情况……就说这么多了。

### 其他说明

本站所有`Diff`代码块的缩进，可能因早期书写时不规范而存在问题，后续将进行调整。调整之后，除非特别说明，否则默认所有 Diff 代码块在添加了前面的`+`或`-`之前缩进是正确的，实际使用时请**去除**这些标记并且**不要**补上空格。

`+`和`-`符号用于高亮删除和添加的行，是为了方便理解代码前后差异而写，在实际书写时应该去除。

例如 Python 中某个简单的示例如下（仅用于演示）：
```diff
while True:
    try:
        a = int(input("输入年份："))
        break
    except ValueError:
        print("请输入正确年份")

-a=int(input("输入年份："))
if a % 4 == 0 and (a % 100 != 0 or a % 400 == 0):
+    print(a,"年是闰年")
else:
    print(a,"年不是闰年")
```
那么实际上应该编写的是应该写的是：
```python
while True:
    try:
        a = int(input("输入年份："))
        break
    except ValueError:
        print("请输入正确年份")

# "a=int(input("输入年份："))"这行代码在编写时应去除
if a % 4 == 0 and (a % 100 != 0 or a % 400 == 0):
    print(a, "年是闰年") # 不要补空格
else:
    print(a, "年不是闰年")
```

2024.8 之后的文章都是如此，以前的文章将会在后续进行缩进调整。如果你知道其实际缩进情况，也可以在使用时自主调整。
