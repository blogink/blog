移动端 Epic Games 如何领取游戏

发表于2026-05-23|更新于2026-05-23|经验记录
|总字数:1.1k|阅读时长:3分钟|浏览量:

最近突然发现《Monument Valley Ⅲ》在 Epic 上限免了（只有移动端），于是领取之。

虽然 Epic~~（不只有）~~客户端是真烂，但有时候送的游戏还不错，只能忍下来了。

客户端安装与登录

使用不同的设备访问 Epic Games 商城网站，点击顶部导航中的下载按钮，网站会自动检测设备并下载合适的安装包。移动端安装前需在系统设置中开启“允许安装未知来源应用”权限，安装完成后授予必要的权限。安装完成后启动客户端，按照要求登录即可。

对于桌面端，我实在不想用 Epic Games Launcher，于是我找到了另一款名为 HeroicGamesLauncher 的客户端代替之。访问其 GitHub 仓库，找到 Releases 区域，下载符合自己设备的（Linux、Mac、Windows）最新的安装文件并安装。

登录流程都差不多，和其他的网站一样：

  1. 打开客户端，点击主界面“登录”按钮。
  2. 选择登录方式：邮箱密码，或是其他渠道或平台授权。
  3. 点击确认后，客户端会尝试调用系统浏览器完成 OAuth 授权（当然你也可以不创建）。
  4. 授权成功后页面自动跳回客户端。

若使用第三方的客户端，则需要根据启动器的设计来选择登录。以 HeroicGamesLauncher 为例，在左侧菜单找到商店-Epic 商店，在右侧登录就行（这部分和网页上登录的做法一致，因为这里就是网页套壳）。完成后点击左侧菜单中的游戏库，等待同步，完成后即可在此安装游戏。（如果加载不出来可以试试这些方法：1、清理 Heroic 缓存；2、自行解决网络环境问题。）

移动端 404 错误

我的手机在客户端中登录后，会跳转至404 Not Found这样的页面。我手动找入口进入了商城，可以浏览游戏，也可以正常领取。按我的想法，登录成功了，应该可以下载游戏了，但我找不到所谓“库”的入口了；网页中下载客户端的按钮仍然在。我还以为这是 Epic 真摆烂导致的（PS：难道不是吗），然后发现这界面和网页毫无差别，后来才意识到我其实没完全登录成功。

这个问题几乎打破了我玩上移动端 Epic 游戏的期待。许久之后再次尝试（期间还更新了一次客户端）仍然不行，忽然想起它是调用浏览器来登录的——如果我换个浏览器呢？

接下来我用模拟器演示一下，具体操作需要根据自己手机的情况调整：

  • 打开手机“设置”，找到“默认应用”之类的选项（实在找不到就在设置里搜索一下）。
  • 在“浏览器”项目中，将默认项由系统自带浏览器更改为第三方浏览器（如 Microsoft Edge、Chrome、Firefox 等）。
  • 返回 Epic 客户端，重新点击登录，确保自己使用了第三方浏览器。

之后正常登录即可，在第三方浏览器中完成账号授权，授权完成后将自动返回 Epic 客户端。仍然不行的话尝试清除缓存与 Cookie。

（话说移动端我没找到库在哪，据闻它和 PC 端的还不能互相查看，网页端有些功能是缺的。对于没有装官方启动器的用户而言，想要看自己入库了哪些游戏，有个办法就是在网页端点击右上角头像找到账户，在付款和奖励中点击交易-购买，根据交易纪录确认自己的库存。此外要么记得游戏名称去搜索一下，要么用小黑盒这种第三方的工具查看。）

游戏下载与安装

完成后，我们向下滑动，找到免费游戏部分，点击获取后下载（我已经领取并安装过了，所以这里显示是已领取的状态）。

下载过程中尽量保持客户端前台运行或允许后台运行权限；考虑到网络问题，如果多次尝试下载失败建议自备加速器解决。

完成后会调用系统安装程序，正常安装即可；部分游戏首次启动会要求使用 Epic 验证，自动跳转到客户端内处理就行。
