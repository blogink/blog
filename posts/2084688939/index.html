利用 Serv00 搭建自己的域名邮箱

发表于2026-03-22|更新于2026-08-18|软件经验
|总字数:2006|阅读时长:8 分钟|浏览量:

虽然现在 Serv00 新增了许多限制（甚至 Alist、哪吒探针也在内），且注册环境要求较高，但仍然是有其价值的（支持 SSL 的免费虚拟主机不大常见）。

有时为了一些事情需要使用邮箱，又不想污染自己的主力邮箱，又或是想显得高级一些，如果你有域名的话，可以搭建自己的域名邮箱。虽然 Cloudflare 提供电子邮件功能，但只能实现收件，发件需要借助其他的服务。Serv00 自带邮箱功能且较为完善，收发件都实现了，连 IMAP、POP、SMTP 功能都有，还提供了一个邮箱管理页面。

这里我们需要准备两个东西：一个托管在 Cloudflare 的域名（免费域名如eu.org、dpdns.org、zabc.net等等也都可以，只要能顺利添加到 Cloudflare 上托管就行），一个正常使用的 Serv00 账号。

添加域名

登录 DevilWEB 管理面板（在注册 Serv00 账户时会向注册邮箱发送一封邮件，里面包含了大部分可能用到的地址，每个人的可能不一样）。

登入面板后，找到左侧WWW website选项点击切换，在右侧选择Add website选项卡，填入你想用作邮箱的域名。例如，若希望使用admin@mail.example.com，那么就在Domain输入框中填写mail.example.com，点击Add完成添加。

随后，我们切换到左侧DNS zones选项卡，在右侧Zone list找到刚才添加的mail.example.com并点击edit，查看目前已有的 DNS 解析。我们记录下这两组参数：

Record nameTypePriorityWeightTTLTarget
mail.example.comMX103600mail5.serv00.com
mail.example.comTXT【无】3600v=spf1 mx a include:mail5.serv00.com -all

注意，每个人这里的参数可能不一样，请根据自己的实际情况来处理。

记录下来后，打开 Cloudflare 的控制台 https://dash.cloudflare.com/ 并选择相应的域名（例如刚才的example.com；当然，如果你用了其他的 DNS 解析工具例如阿里云、腾讯云等，操作同理），找到DNS-记录一项（Cloudflare 的控制台界面相较于之前发生了较大的变化，这里请自行查找），在该域名的管理【域名】的 DNS处点击添加记录按钮，添加两条记录，分别为 MX 和 TXT，名称均写mail（和先前在 Serv00 处添加的子域名名称保持一致；若之前写了mail1.example.com那么这里名称就写mail1，以此类推）。

以刚才的示例，MX 记录中邮件服务器写前面 MX 记录中的值（例如mail5.serv00.com），TTL 选择1 小时（3600 秒），优先级填写10，写好后点击保存。再添加 TXT 记录，名称为mail，TTL 也为1 小时，内容填写v=spf1 mx a include:mail5.serv00.com -all，然后保存。

创建邮箱

返回 Serv00 控制台，进入左侧E-mail选项卡，点击右侧Add new e-mail选项卡，新增一个邮箱。我为了方便管理，此处填写admin@mail.example.com。完成后选择Domain list选项卡，找到刚才添加的域名mail.example.com，点击右侧Details按钮进入该域名邮箱对应的Mailbox list界面。

在这个界面，我们切换到Add new mailbox选项卡，添加一个别的名称的邮箱（例如test@mail.example.com）并设置密码，点击Add。

返回Details for 【域名】这个选项卡，找到刚才创建的邮箱账号并点击旁边的Set quota按钮，设置当前邮箱账户最大容量。Serv00 给每个账户分配了总共 3GB 的存储空间，建议这里设置为 100MB（应该够用了）。

接下来，我们回到E-mail项目最初界面，点击Open web client选项卡（也可以直接访问 https://mail.serv00.com/），进入邮箱登录界面。在这里输入完整的用户名（如test@mail.example.com）和密码（忘了就回刚才Details for 【域名】找到对应邮箱的Change password自行修改），如果配置顺利则可成功登入邮箱（Serv00 设计了新的界面，比过去的要现代化一些），可以在此测试收发邮件是否正常。

为了防止被拦截，防止传输过程中被篡改，我们可以配置 DKIM。前往E-mail的Domain list选项卡，找到刚才配置的邮箱域名，点击旁边的DKIM按钮，它会给你显示一段内容，是 DNS 解析相关的。

无限域名邮箱

刚才的设置只能有一个邮箱，但如果我们想要test1@mail.example.com、test2@mail.example.com、test3@mail.example.com等等都能用该怎么办？

进入E-mail项目并点击Add new alias选项卡，在该界面点击下面蓝字Advanced settings，将Alias type设置为Catch-all。此时上方会多出来Catch-all domain输入框，在这里我们填写域名（不需要带@，例如mail.example.com），E-mail address (from)这里填写邮箱后缀（这里需要带上@了），将E-mail address (to)设置为你的目标邮箱（都由这个目标邮箱账号代收）。完成后点击Add。之后的 DNS 记录填写方式同上。

附上一些 Tips：

Serv00 是可以切换 PHP 版本的

通常情况下，网站文件应该放在/usr/home/USERID/domains/DOMAIN/public_html目录下（USERID和DOMAIN根据自己的情况替换），接下来涉及路径的内容都据此展开。

在对应网站的根目录（public_html中）创建.htaccess文件，并在整个文件的末尾选一条添加（如有类似于IfModule这样的重写配置，那就放到这个标签外面）。以下是截至 2026 年 Serv00 支持的 PHP 版本：

新的交互界面

现在 Serv00 提供了 DevilWEB 2.1 交互界面，整体看上去更加优雅了，但我觉得变卡了。好在切换成新的外观后，仍可以在左下角用户菜单找到切换回 Legacy 外观的按钮。

PHP eval()函数

对于 PHP 网站，可以在面板中Website list一项点击对应的网站（旧版外观是Manage-Details），然后找到eval() Function，即可允许运行 PHP 的eval()函数。如果使用了利用该函数加密的程序或主题，建议启用。

杂项

Serv00 支持的运行环境不只有 PHP。它还可以运行 Node.js、Python、Ruby、Java、Perl、Kotlin、Mise（但没有 ASP）。这在面板中创建网站时可以选择。

Serv00 运行的不是 Linux 系统（用的是 FreeBSD），而且每个账户分配的运行内存和磁盘都比较有限，运行大型项目是别想了。但这个主机的隔离性似乎不太好（例如可以超出 CPU 限制运行较长时间，不过不建议主动这么做）。而且它还支持 SSH 连接，还可以创建自定义端口……在轻度折腾下，你几乎可以将其当作一台普通 VPS 来用。
